# ReShade Preset Catalog

[Effect usage](Catalog.md#effect-usage) · [Full preset catalog](Catalog.md)

This collection contains 89 saved ReShade presets across 38 game folders. The catalog lists the enabled techniques in each preset and describes the likely purpose of their combination. The usage ranking counts how many presets enable each included technique.

The preset files are under [presets/](presets/). Each preset uses the shader files identified by its enabled techniques. Some presets use custom effects. The collection contains preset settings, and the descriptions are inferred from those settings.
